# Program loop

```text
LOAD STATE
→ VERIFY INPUTS
→ SELECT FIRST INCOMPLETE WAVE
→ DISCOVERY SUBAGENTS
→ IMPLEMENT
→ TEST
→ REVIEW SUBAGENTS
→ REPAIR IF NEEDED
→ CHECKPOINT
→ NEXT WAVE
→ FINAL AUDIT
```

Never pause after checkpoint. A checkpoint is a machine recovery boundary, not a human approval gate.
